# 스택은 괄호의 유효성을 어떻게 검사하는가?

## 한 줄 설명

여는 괄호를 스택에 쌓고 닫는 괄호를 만날 때 가장 최근 여는 괄호를 꺼내 짝을 확인한다.

## 왜 필요한가

가장 나중에 열린 괄호가 가장 먼저 닫혀야 하므로 LIFO 구조인 스택의 순서와 정확히 맞는다.

## 핵심 코드

```python
def is_vps(test_case):
    stack = []

    for parenthesis in test_case:
        if parenthesis == "(":
            stack.append(parenthesis)
        else:
            if len(stack) == 0:
                return False
            stack.pop()

    return len(stack) == 0
```

## 꼭 기억할 점

- 닫는 괄호가 나왔는데 스택이 비어 있으면 잘못된 문자열이다.
- 순회가 끝난 뒤 여는 괄호가 남아 있어도 잘못된 문자열이다.
- `((()))()`는 참이고 `((())`, `)))(((`는 거짓이다.
