# 버블 정렬은 어떻게 동작하는가?

## 한 줄 설명

버블 정렬은 서로 이웃한 두 값을 비교해 순서가 잘못됐으면 교환하는 과정을 반복한다.

## 왜 필요한가

정렬 알고리즘의 비교와 교환 흐름을 가장 단순하게 연습할 수 있으며, 정렬된 데이터는 이진 탐색 같은 알고리즘의 전제가 된다.

## 핵심 코드

```python
array = [45, 7, 12, 82, 25]

for j in range(4, 0, -1):
    for i in range(j):
        if array[i] > array[i + 1]:
            array[i], array[i + 1] = array[i + 1], array[i]
```

## 꼭 기억할 점

- 한 바퀴가 끝나면 가장 큰 값 하나가 오른쪽 끝에 자리 잡는다.
- 비교 범위는 정렬된 오른쪽 부분을 제외하며 줄어든다.
- 구현은 쉽지만 데이터가 많을 때 비교 횟수가 크게 늘어 효율적이지 않다.
- 실제 Python 코드에서는 보통 `sort()`나 `sorted()`를 사용한다.
