# 스택과 큐는 데이터 순서가 어떻게 다른가?

## 한 줄 설명

스택은 마지막에 넣은 데이터를 먼저 꺼내는 LIFO 구조이고, 큐는 먼저 넣은 데이터를 먼저 꺼내는 FIFO 구조다.

## 왜 필요한가

되돌리기·괄호 검사에는 최근 항목부터 처리하는 스택이, 대기열에는 도착 순서대로 처리하는 큐가 어울린다.

## 핵심 코드

```python
# Stack
stack = []
stack.append(10)
stack.append(20)
print(stack.pop())  # 20

# Queue
from collections import deque
queue = deque()
queue.append(10)
queue.append(20)
print(queue.popleft())  # 10
```

## 꼭 기억할 점

- 스택의 대표 연산은 `push`, `pop`, `peek`다.
- Python 리스트는 `append()`와 `pop()`으로 스택처럼 쓸 수 있다.
- 큐는 리스트 맨 앞 삭제보다 `deque.popleft()`가 적합하다.
- 수업의 미실행 예제 `s.peak()`는 `s.peek()`의 오탈자다.
