# 연결 리스트는 노드를 어떻게 연결하는가?

## 한 줄 설명

연결 리스트는 각 노드가 데이터와 다음 노드를 가리키는 `next` 참조를 저장해 순서를 만든다.

## 왜 필요한가

배열처럼 모든 요소를 연속된 공간에 둘 필요가 없고, 노드 사이 연결을 바꿔 구조를 조정할 수 있다.

## 핵심 코드

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class Linked_List:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            return

        current = self.head
        while current.next is not None:
            current = current.next
        current.next = new_node
```

## 꼭 기억할 점

- `head`는 첫 노드를 가리킨다.
- 마지막 노드의 `next`는 `None`이다.
- 특정 위치에 접근하려면 앞 노드부터 연결을 따라가야 한다.
- 수업의 스택과 큐도 같은 `Node` 연결 원리로 구현했다.
