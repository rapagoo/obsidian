# 정적 배열과 동적 배열은 어떻게 다른가?

## 한 줄 설명

정적 배열은 생성할 때 정한 용량이 고정되고, 동적 배열은 필요에 따라 저장 공간의 크기를 늘릴 수 있다.

## 왜 필요한가

배열은 인덱스로 빠르게 접근할 수 있지만 중간 삽입에는 뒤쪽 요소를 이동해야 한다. Python 리스트가 내부에서 동적 배열로 동작하는 이유를 이해할 수 있다.

## 핵심 코드

```python
class Static_Array:
    def __init__(self, capacity):
        self.capacity = capacity
        self.array = [0] * capacity
        self.size = 0

    def insert(self, index, value):
        for i in range(self.capacity - 1, index, -1):
            self.array[i] = self.array[i - 1]
        self.array[index] = value
        self.size += 1
```

## 꼭 기억할 점

- 배열의 인덱스 접근은 빠르다.
- 중간 삽입·삭제는 여러 요소 이동이 필요하다.
- Python 리스트는 크기를 늘릴 수 있는 동적 배열이다.
- 수업 구현은 자료구조 원리를 보여 주는 단순화된 예제다.
