# 이진 탐색은 왜 정렬된 데이터가 필요한가?

## 한 줄 설명

이진 탐색은 가운데 값과 찾을 값을 비교해 탐색 범위를 왼쪽 또는 오른쪽 절반으로 계속 줄인다.

## 왜 필요한가

처음부터 하나씩 찾는 대신 매번 후보를 절반으로 줄여 큰 데이터에서도 빠르게 검색할 수 있다.

## 핵심 코드

```python
left = 0
right = len(arr) - 1
answer = -1

while left <= right:
    mid = (left + right) // 2

    if arr[mid] < search:
        left = mid + 1
    elif arr[mid] > search:
        right = mid - 1
    else:
        answer = mid
        break
```

## 꼭 기억할 점

- 데이터가 정렬돼 있어야 중간값 비교로 어느 절반을 버릴지 판단할 수 있다.
- 값이 작으면 `right`, 크면 `left`를 중간 다음 위치로 옮긴다.
- 종료 조건은 `left <= right`다.

> [!warning]
> 수업의 두 번째 변형 코드는 `search=7`이 있어도 없다고 출력하는 잘못된 종료 검사를 포함한다. 위 코드는 같은 노트북의 정상 동작 구현을 기준으로 정리했다.
