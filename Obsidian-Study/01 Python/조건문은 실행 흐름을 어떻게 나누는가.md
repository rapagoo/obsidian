# 조건문은 실행 흐름을 어떻게 나누는가?

## 한 줄 설명

조건문은 비교 결과가 `True`인지 `False`인지에 따라 서로 다른 코드 블록을 실행한다.

## 왜 필요한가

프로그램은 입력과 상황에 따라 다른 행동을 해야 한다. 예를 들어 점수에 따라 등급을 정하거나 숫자가 짝수인지 판단할 때 조건문을 사용한다.

## 핵심 코드

```python
score = 70

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("F")
```

## 꼭 기억할 점

- `if`부터 검사하고, 거짓이면 순서대로 `elif`, 마지막으로 `else`를 확인한다.
- 실행할 블록은 같은 들여쓰기 깊이를 가져야 한다.
- `and`, `or`, `not`으로 여러 조건을 결합할 수 있다.
- `a if 조건 else b`는 간단한 값을 선택하는 삼항 표현식이다.
