# 재귀 함수는 언제 자신을 다시 호출하는가?

## 한 줄 설명

재귀 함수는 큰 문제를 같은 형태의 더 작은 문제로 줄이기 위해 자기 자신을 다시 호출하는 함수다.

## 왜 필요한가

피보나치 수열이나 트리 탐색처럼 동일한 규칙이 작은 단계로 반복될 때 문제의 정의를 코드에 직접 표현할 수 있다.

## 핵심 코드

```python
def fibonacci(n):
    if n <= 2:
        return 1

    return fibonacci(n - 1) + fibonacci(n - 2)
```

## 꼭 기억할 점

- 호출을 멈추는 종료 조건이 반드시 있어야 한다.
- 종료 조건이 없으면 호출이 계속 쌓여 `RecursionError`가 발생한다.
- 수업의 단순 피보나치 구현은 같은 값을 반복 계산하므로 `fibonacci(38)`도 수 초가 걸렸다.
- 재귀 호출은 호출 정보를 스택에 쌓는다.
