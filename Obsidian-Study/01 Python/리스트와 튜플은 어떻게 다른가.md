# 리스트와 튜플은 어떻게 다른가?

## 한 줄 설명

리스트와 튜플은 모두 순서가 있는 자료구조이지만, 리스트는 생성 후 요소를 바꿀 수 있고 튜플은 바꿀 수 없다.

## 왜 필요한가

메뉴처럼 계속 추가·수정되는 값은 리스트에, 한 번 정한 뒤 바뀌면 안 되는 값은 튜플에 담으면 데이터의 의도를 코드에 드러낼 수 있다.

## 핵심 코드

```python
lunch_menu = ["짜장면", "돈까스", "제육볶음"]
lunch_menu.append("김치찌개")

dinner_menu = ("떡볶이", "닭갈비", "삼겹살")
```

## 꼭 기억할 점

- 리스트는 `[]`, 튜플은 `()`로 작성한다.
- 둘 다 인덱싱, 슬라이싱, `len()`, `in`을 사용할 수 있다.
- 리스트는 `append`, `insert`, `remove`, 인덱스 대입으로 변경할 수 있다.
- 튜플 요소에 값을 대입하면 `TypeError`가 발생한다.
