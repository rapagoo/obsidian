# 상속과 오버라이딩은 어떻게 코드를 재사용하는가?

## 한 줄 설명

상속은 부모 클래스의 멤버를 자식 클래스가 물려받는 기능이고, 오버라이딩은 물려받은 메서드를 자식의 방식으로 다시 정의하는 것이다.

## 왜 필요한가

여러 클래스의 공통 속성과 기능을 부모에 한 번만 작성하면 중복을 줄일 수 있다. 다른 행동이 필요한 부분만 자식 클래스에서 바꾼다.

## 핵심 코드

```python
class Mammal:
    def eat(self):
        print("먹는다")

    def mammal(self):
        print("젖을 먹인다")

class Killer_Whale(Mammal):
    def eat(self):
        print("생선 먹는다")
```

## 꼭 기억할 점

- `class 자식(부모):` 형태로 상속한다.
- 다시 정의하지 않은 메서드는 부모의 것을 사용한다.
- 같은 `eat()` 호출이 객체 종류에 따라 다르게 동작하는 성질을 다형성이라고 한다.
- 공통 특징만 추출해 부모를 설계하는 과정은 추상화와 연결된다.
