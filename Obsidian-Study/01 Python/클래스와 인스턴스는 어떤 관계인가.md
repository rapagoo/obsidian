# 클래스와 인스턴스는 어떤 관계인가?

## 한 줄 설명

클래스는 데이터와 기능을 정의한 설계도이고, 인스턴스는 그 설계도로 실제 생성한 각각의 객체다.

## 왜 필요한가

이름·체력·공격처럼 서로 관련된 데이터와 행동을 하나로 묶으면 현실의 대상을 코드로 표현하고 여러 객체를 일관되게 만들 수 있다.

## 핵심 코드

```python
class Contact:
    def __init__(self, name, age, tel):
        self.name = name
        self.age = age
        self.tel = tel

    def __str__(self):
        return f"이름: {self.name}, 나이: {self.age}"

contact1 = Contact("나예호", 20, "010-1234-5678")
print(contact1)
```

## 꼭 기억할 점

- `__init__`은 인스턴스를 만들 때 초기값을 설정하는 생성자다.
- `self`는 현재 메서드를 호출한 인스턴스 자신을 가리킨다.
- 같은 클래스에서 만든 인스턴스도 각자의 상태를 가질 수 있다.
- `__str__`은 `print(인스턴스)`에 사용할 문자열 표현을 반환한다.
