# 변수는 왜 사용하는가?

## 한 줄 설명

변수는 값을 메모리에 저장해 이름으로 다시 꺼내 쓰는 공간이다. 같은 값이 여러 번 쓰이거나 나중에 바뀔 수 있을 때 코드를 읽고 수정하기 쉬워진다.

## 왜 필요한가

숫자 자체를 코드 곳곳에 반복하면 값이 바뀔 때 모두 찾아 고쳐야 한다. 의미 있는 이름을 붙이면 무엇을 나타내는 값인지도 알 수 있다.

## 핵심 코드

```python
num1 = 1000
num2 = 50

print(num1 + num2)
print(num1 - num2)
```

## 꼭 기억할 점

- `=`은 오른쪽 값을 계산한 뒤 왼쪽 변수에 저장하는 대입 연산자다.
- 변수에는 정수, 실수, 문자열, 논리값 등 여러 자료형을 저장할 수 있다.
- `print = 10`처럼 내장 함수 이름을 변수로 쓰면 이후 `print()` 호출에서 `TypeError`가 발생한다.
- Python 키워드는 변수명으로 사용할 수 없다.
