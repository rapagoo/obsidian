# 얕은 복사와 깊은 복사는 어떻게 다른가?

## 한 줄 설명

얕은 복사는 바깥 컨테이너만 새로 만들고 내부 중첩 객체는 공유하지만, 깊은 복사는 중첩 객체까지 재귀적으로 새로 만든다.

## 왜 필요한가

복사본을 수정했는데 원본까지 바뀌는 문제는 두 변수가 같은 객체나 같은 내부 객체를 가리킬 때 생긴다.

## 핵심 코드

```python
import copy

snacks = ["맛동산", ["솔의눈", "데자와"]]
shallow = copy.copy(snacks)
deep = copy.deepcopy(snacks)

deep[1][0] = "아침햇살"
```

## 꼭 기억할 점

- `list_temp = list_original`은 복사가 아니라 같은 객체를 가리키는 참조 대입이다.
- 얕은 복사본의 중첩 리스트를 수정하면 원본에도 반영될 수 있다.
- 중첩 구조가 없으면 얕은 복사로도 충분한 경우가 많다.
- pandas에서는 원본 보존을 위해 `df.copy()`로 작업용 DataFrame을 만드는 흐름을 사용했다.
