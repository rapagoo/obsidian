# 모듈과 import는 코드를 어떻게 나누는가?

## 한 줄 설명

모듈은 함수와 클래스를 모아 둔 `.py` 파일이며, `import`는 다른 파일의 코드를 현재 프로그램에서 사용할 수 있게 불러온다.

## 왜 필요한가

모든 코드를 한 파일에 작성하면 찾고 수정하기 어렵다. 기능별로 나누면 재사용과 테스트가 쉬워진다.

## 핵심 코드

```python
import cal
print(cal.mul(3, 5))

from cal import absolute
print(absolute(-5))
```

## 꼭 기억할 점

- `import 모듈`은 `모듈.함수()` 형태로 출처를 명확히 한다.
- `from 모듈 import 함수`는 함수 이름을 바로 사용할 수 있다.
- 모듈을 불러올 때 파일 최상위 코드가 실행된다.
- 직접 실행할 때만 필요한 코드는 `if __name__ == "__main__":` 아래에 둔다.
