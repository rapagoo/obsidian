# 인덱싱과 슬라이싱은 어떻게 동작하는가?

## 한 줄 설명

인덱싱은 한 위치의 요소를 가져오고, 슬라이싱은 시작 위치부터 끝 위치 바로 전까지 여러 요소를 잘라 가져온다.

## 왜 필요한가

여러 값을 저장한 뒤 원하는 일부만 선택하려면 위치를 이용해야 한다. 음수 인덱스는 뒤에서부터 세기 때문에 마지막 요소에 쉽게 접근할 수 있다.

## 핵심 코드

```python
lunch_menu = ["짜장면", "돈까스", "제육볶음", "왕만두", "김치찌개"]

print(lunch_menu[0])     # 짜장면
print(lunch_menu[-1])    # 김치찌개
print(lunch_menu[1:4])   # ['돈까스', '제육볶음', '왕만두']
```

## 꼭 기억할 점

- 첫 번째 인덱스는 `0`이다.
- `-1`은 마지막 요소, `-2`는 뒤에서 두 번째 요소다.
- `값[시작:끝]`에서 시작은 포함하고 끝은 포함하지 않는다.
- 시작을 생략하면 처음부터, 끝을 생략하면 마지막까지 선택한다.
- 범위를 벗어난 단일 인덱싱은 `IndexError`를 발생시킨다.
