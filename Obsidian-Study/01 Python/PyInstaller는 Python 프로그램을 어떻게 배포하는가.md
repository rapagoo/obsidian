# PyInstaller는 Python 프로그램을 어떻게 배포하는가?

## 한 줄 설명

PyInstaller는 Python 실행 환경과 필요한 모듈을 묶어, 별도의 Python 설치 없이 실행할 수 있는 프로그램 파일을 만드는 도구다.

## 왜 필요한가

수업에서 만든 PySide6 웹캠 프로그램을 다른 컴퓨터에서 실행하려면 Python과 라이브러리를 하나씩 설치해야 한다. 실행에 필요한 구성요소를 함께 묶으면 전달과 실행이 단순해진다.

## 핵심 코드

```python
!pyinstaller --onefile live_webcam.py
```

## 꼭 기억할 점

- `--onefile`은 배포 파일을 하나의 실행 파일로 묶는 옵션이다.
- 수업 주석에는 생성된 파일 크기가 약 275MB라고 기록되어 있다.
- 이미지, 모델 가중치, `.task` 파일처럼 코드 밖에서 읽는 파일은 자동으로 포함되는지 별도로 확인해야 한다.
- 배포 전에 `live_webcam.py` 자체가 독립 실행되는지 먼저 확인한다.
