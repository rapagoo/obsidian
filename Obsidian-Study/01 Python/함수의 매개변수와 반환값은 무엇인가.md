# 함수의 매개변수와 반환값은 무엇인가?

## 한 줄 설명

매개변수는 함수가 처리할 값을 받는 이름이고, 반환값은 함수가 계산을 끝낸 뒤 호출한 곳으로 돌려주는 결과다.

## 왜 필요한가

반복되는 로직을 함수로 만들면 코드를 재사용할 수 있고, 기능을 작은 단위로 나눠 읽고 수정하기 쉬워진다.

## 핵심 코드

```python
def add_two_number(num1, num2):
    return num1 + num2

result = add_two_number(3, 5)
print(result)
```

## 꼭 기억할 점

- 정의부의 `num1`, `num2`는 매개변수이고 호출할 때 전달한 `3`, `5`는 인자다.
- `return`이 실행되면 함수는 끝나며 결과가 호출한 곳으로 돌아간다.
- `print()`만 하는 함수의 반환값은 `None`이다.
- 여러 값을 쉼표로 반환하면 실제로는 하나의 튜플로 반환된다.
- `*args`는 여러 위치 인자를 튜플로 받는다.
