# 캡슐화에서 이중 밑줄은 무엇을 의미하는가?

## 한 줄 설명

캡슐화는 객체 내부 상태에 대한 직접 접근을 줄이고 정해진 메서드를 통해 다루게 하는 설계이며, `__name` 형태는 이름 변경(name mangling)을 적용한다.

## 왜 필요한가

잔액이나 체력처럼 규칙을 지켜 변경해야 하는 값을 외부에서 마음대로 바꾸면 객체 상태가 잘못될 수 있다. 메서드를 통하면 검사와 보정 로직을 한곳에 둘 수 있다.

## 핵심 코드

```python
class Account:
    def __init__(self):
        self.__money = 0

    def deposit(self, money):
        self.__money += money

    def show_money(self):
        return self.__money
```

## 꼭 기억할 점

- `__money`는 완전한 보안 장치가 아니라 실수로 접근하기 어렵게 이름을 바꾸는 기능이다.
- 값을 읽는 메서드를 getter, 바꾸는 메서드를 setter라고 부른다.
- `obj.__money = 값`은 내부의 이름 변경된 속성을 바꾸지 않고 별도 속성을 만들 수 있다.
- 필요한 동작만 공개하는 것이 캡슐화의 핵심이다.
