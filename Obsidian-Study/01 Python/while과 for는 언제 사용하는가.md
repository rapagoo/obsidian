# while과 for는 언제 사용하는가?

## 한 줄 설명

`while`은 조건이 참인 동안 반복하고, `for`는 문자열·리스트·`range`처럼 순회할 대상이 있을 때 각 요소를 차례로 처리한다.

## 왜 필요한가

같은 코드를 여러 번 복사하지 않고 반복 규칙만 표현할 수 있다. 종료 시점을 조건으로 판단하면 `while`, 반복 범위가 보이면 `for`가 자연스럽다.

## 핵심 코드

```python
while True:
    num = int(input("정수를 입력해주세요"))
    if num == 0:
        break

for num in range(1, 101):
    if num % 3 == 0:
        print(num, end=" ")
```

## 꼭 기억할 점

- `while`의 조건이 계속 참이면 무한 반복되므로 종료 조건이나 `break`가 필요하다.
- `break`는 가장 가까운 반복문 하나를 즉시 끝낸다.
- `range(시작, 끝, 증가량)`에서 끝 값은 포함되지 않는다.
- 중첩 반복문은 별 찍기나 구구단처럼 두 방향의 반복이 있을 때 사용한다.
