# with open은 왜 사용하는가?

## 한 줄 설명

`with open(...)`은 파일을 열어 사용하는 범위를 만들고, 블록이 끝나면 파일을 자동으로 닫아 준다.

## 왜 필요한가

파일을 닫지 않으면 자원이 계속 사용되거나 쓰기 내용이 제대로 반영되지 않을 수 있다. `with`는 정상 실행과 예외 발생 모두에서 닫기 처리를 보장한다.

## 핵심 코드

```python
with open("test2.txt", "r") as file:
    content = file.read()
    print(content)
```

## 꼭 기억할 점

- `"r"`은 읽기, `"w"`는 기존 내용을 지우고 쓰기, `"a"`는 뒤에 추가하기다.
- 바이너리 파일은 `"rb"`, `"wb"`처럼 `b`를 붙인다.
- 텍스트 인코딩이 다른 CSV는 `encoding="EUC-KR"`처럼 명시할 수 있다.
- 파일이 없을 수 있다면 `FileNotFoundError`를 처리한다.
