# validation_split은 왜 사용하는가?

## 한 줄 설명

`validation_split`은 `fit()`에 전달한 학습 데이터 일부를 실제 가중치 학습에는 사용하지 않고 epoch마다 검증 성능을 확인하는 데 사용한다.

## 왜 필요한가

학습 손실만 보면 모델이 학습 데이터를 외우는 중인지 알기 어렵다. 검증 손실과 accuracy를 함께 보면 과적합 징후를 확인할 수 있다.

## 핵심 코드

```python
model.fit(
    X_train,
    y_train,
    epochs=100,
    batch_size=16,
    validation_split=0.25
)
```

## 꼭 기억할 점

- 수업에서는 전체 데이터의 80%를 `X_train`으로 만든 뒤 그중 25%를 검증에 사용했다.
- 검증 데이터는 epoch 중 성능 확인용이며 가중치 업데이트에는 사용되지 않는다.
- 최종 `X_test`는 학습과 모델 선택이 끝난 뒤 별도로 평가한다.
- K-fold는 여러 분할을 반복하지만 `validation_split`은 한 번 정한 검증 분할을 사용한다.
