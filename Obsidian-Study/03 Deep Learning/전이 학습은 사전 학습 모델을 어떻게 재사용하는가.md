# 전이 학습은 사전 학습 모델을 어떻게 재사용하는가?

## 한 줄 설명

전이 학습(transfer learning)은 큰 데이터셋으로 미리 학습한 모델의 가중치를 출발점으로 삼아, 새로운 데이터셋에 맞게 다시 학습하는 방법이다.

## 왜 필요한가

처음부터 모든 특징을 학습하려면 많은 데이터와 시간이 필요하다. 이미 일반적인 이미지 특징을 익힌 모델을 재사용하면 고양이·강아지처럼 새로운 class를 비교적 적은 데이터로 학습할 수 있다.

## 핵심 코드

```python
from yolov5.train import run

run(
    data="pet/data.yaml",
    epochs=5,
    batch_size=64,
    weights="yolov5s.pt",
    device="0"
)
```

## 꼭 기억할 점

- `yolov5s.pt`는 학습을 시작할 때 불러오는 사전 학습 가중치다.
- `pet/data.yaml`에는 새로운 데이터의 경로와 `cat`, `dog` class 정보가 들어 있다.
- 학습이 끝나면 검증 성능이 좋은 가중치 파일을 추론에 사용할 수 있다.
- 전이 학습도 새 데이터의 label과 train·validation 구성이 올바라야 한다.

> [!warning]
> `day0728.ipynb`에 저장된 YOLOv5 학습은 첫 epoch 검증 중 `KeyboardInterrupt`로 중단되었고, YOLOv8 학습 출력도 첫 epoch 진행 중까지만 남아 있다. 이 실행 기록만으로 5 epochs 학습 완료를 확정할 수 없다.
