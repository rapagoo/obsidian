# 손실 함수는 왜 필요한가?

## 한 줄 설명

손실 함수는 모델의 예측과 실제 정답이 얼마나 다른지를 하나의 수치로 계산해 학습이 줄여야 할 목표를 만든다.

## 왜 필요한가

모델은 “틀렸다”는 말만으로 어느 방향으로 얼마나 가중치를 바꿀지 알 수 없다. 손실값의 변화가 optimizer의 수정 방향을 제공한다.

## 핵심 코드

```python
model.compile(
    loss="binary_crossentropy",
    optimizer="adam",
    metrics=["accuracy"]
)
```

## 꼭 기억할 점

- 회귀에서는 MSE 같은 오차를 손실로 사용할 수 있다.
- 이진 분류와 다중 class 분류는 서로 다른 crossentropy 설정을 사용한다.
- `loss`는 학습이 직접 줄이는 값이고 `metrics`는 사람이 성능을 해석하기 위한 값이다.
- 손실이 낮아져도 검증 성능이 함께 좋아지는지 확인해야 한다.
