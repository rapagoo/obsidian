# batch_size는 무엇인가?

## 한 줄 설명

`batch_size`는 한 번의 가중치 업데이트를 위해 묶어서 처리하는 학습 샘플 수다.

## 왜 필요한가

전체 데이터를 한꺼번에 계산하면 메모리가 많이 필요하고 업데이트 횟수가 적다. 작은 묶음으로 나누면 계산과 업데이트를 반복할 수 있다.

## 핵심 코드

```python
model.fit(
    X_train,
    y_train,
    epochs=100,
    batch_size=16
)
```

## 꼭 기억할 점

- 샘플이 120개이고 `batch_size=16`이면 한 epoch에 여러 batch가 생긴다.
- 일반적으로 각 batch의 순전파·손실 계산·역전파 후 가중치가 한 번 업데이트된다.
- 작은 batch는 업데이트가 잦고 변동성이 커질 수 있다.
- 수업에서는 타이타닉에 `64`, iris에 `16`을 사용했다.
