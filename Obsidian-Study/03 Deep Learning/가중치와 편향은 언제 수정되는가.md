# 가중치와 편향은 언제 수정되는가?

## 한 줄 설명

가중치와 편향은 batch의 예측과 정답으로 손실을 계산하고 역전파로 gradient를 구한 뒤 optimizer가 업데이트할 때 수정된다.

## 왜 필요한가

가중치는 각 입력 특징의 영향력을, 편향은 활성화 기준의 위치를 조절한다. 이 값들이 바뀌면서 모델의 예측 경계가 데이터에 맞춰진다.

## 핵심 흐름

1. 입력을 앞 방향으로 전달해 예측한다.
2. 손실 함수로 정답과 예측의 차이를 계산한다.
3. 역전파로 각 파라미터가 손실에 미친 영향을 구한다.
4. optimizer가 가중치와 편향을 수정한다.

## 꼭 기억할 점

- 보통 batch 하나를 처리할 때마다 한 번 업데이트한다.
- epoch는 전체 데이터를 모두 본 횟수이므로 한 epoch 안에 여러 업데이트가 있다.
- `evaluate()`와 `predict()`에서는 학습하지 않으므로 가중치를 바꾸지 않는다.
- `w`는 weight, `b`는 bias이며 선형식 `H(x) = wx + b`에서 출발한다.
