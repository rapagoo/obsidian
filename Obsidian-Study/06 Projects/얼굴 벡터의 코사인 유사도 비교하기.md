# 얼굴 벡터의 코사인 유사도 비교하기

## 실습 목표

저장된 얼굴 이미지와 웹캠 얼굴을 `face_recognition`으로 벡터화하고 코사인 유사도를 계산한다.

## 전체 흐름

1. 기준 얼굴 이미지에서 face encoding을 추출한다.
2. 웹캠 frame을 BGR에서 RGB로 변환한다.
3. 현재 frame에서 얼굴 위치와 encoding을 찾는다.
4. 기준 벡터와 현재 벡터의 코사인 유사도를 계산한다.
5. 웹캠과 기준 이미지를 나란히 표시한다.

## 핵심 코드

```python
face_img = face_recognition.load_image_file("celeb.jpg")
face_encoding = face_recognition.face_encodings(face_img)
face_vec = face_encoding[0]

real_img = face_recognition.face_locations(cvt_image)
real_encoding = face_recognition.face_encodings(cvt_image, real_img)

if real_encoding:
    real_vec = real_encoding[0]
    similarity = get_cosine_similarity(real_vec, face_vec)
```

> [!warning]
> 앞선 셀에는 `ModuleNotFoundError: No module named 'face_recognition'`이 기록되어 있다. 이후 실습을 실행하려면 현재 가상환경에 라이브러리와 관련 의존성이 정상 설치됐는지 확인해야 한다.

> [!warning]
> `face_encodings()`가 빈 리스트를 반환할 수 있으므로 `[0]`을 사용하기 전에 얼굴이 검출됐는지 확인해야 한다. 수업 코드는 기준 이미지 부분을 `try`로 감쌌다.
