# 타이타닉 데이터를 전처리하고 모델 비교하기

## 실습 목표

타이타닉의 범주형·결측 데이터를 모델이 사용할 수 있게 전처리하고 KNN, 결정 트리, SVM, 로지스틱 회귀를 비교한다.

## 전체 흐름

1. CSV를 DataFrame으로 불러오기
2. `Sex`, `Embarked`를 수치형 열로 변환
3. 사용할 열 선택과 결측치 제거
4. `X`, `y` 분리
5. 학습·테스트 데이터 분리
6. 모델 학습과 accuracy 계산

## 핵심 코드

```python
df_titanic = pd.read_csv("titanic.csv")
df_tt = df_titanic.copy()

df_tt["female"] = df_tt["Sex"].apply(
    lambda x: 1 if x == "female" else 0
)
df_tt["male"] = df_tt["Sex"].apply(
    lambda x: 1 if x == "male" else 0
)
df_tt = pd.get_dummies(df_tt, columns=["Embarked"], dtype=int)

df_tt = df_tt[
    ["Pclass", "female", "male", "Age",
     "Embarked_C", "Embarked_Q", "Embarked_S", "Survived"]
].dropna()

X = df_tt.iloc[:, :-1]
y = df_tt.iloc[:, -1]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, random_state=20
)
```

SVM은 같은 분할에 `StandardScaler`를 적용한 뒤 `SVC(kernel="rbf", C=1.0, random_state=20)`로 학습했다.
