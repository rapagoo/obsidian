# 포켓몬 배틀을 클래스로 만들기

## 실습 목표

포켓몬의 이름·타입·체력·힘을 하나의 객체로 묶고, 객체가 다른 객체를 공격하도록 설계한다.

## 전체 흐름

1. 생성자로 포켓몬 상태 초기화
2. private 체력을 getter로 확인
3. 공격력에 난수를 더해 damage 계산
4. 상대의 `take_damage()` 호출
5. 체력이 0이 될 때까지 반복

## 핵심 코드

```python
class Pokemon:
    def __init__(self, name, poke_type, hp, power):
        self.__name = name
        self.__poke_type = poke_type
        self.__hp = hp
        self.__power = power

    def get_hp(self):
        return self.__hp

    def take_damage(self, damage):
        self.__hp -= damage
        if self.__hp < 0:
            self.__hp = 0

    def attack(self, target):
        import random
        damage = self.__power + random.randint(-3, 3)
        target.take_damage(damage)

water = Pokemon("꼬부기", "물", 100, 10)
grass = Pokemon("이상해씨", "풀", 120, 8)

while water.get_hp() > 0 and grass.get_hp() > 0:
    water.attack(grass)
    if grass.get_hp() == 0:
        break
    grass.attack(water)
```

> [!warning]
> 수업 원본에서는 한 포켓몬의 체력이 0이 된 뒤에도 같은 turn의 다음 공격이 실행될 수 있다. 위 핵심 코드에서는 승리 확인 후 `break`하는 위치를 학습 포인트로 표시했다.
