# 정확도 정밀도 재현율 F1은 어떻게 다른가?

## 한 줄 설명

정확도는 전체 정답 비율, 정밀도는 Positive 예측의 신뢰도, 재현율은 실제 Positive를 찾아낸 비율이며 F1은 정밀도와 재현율의 조화 평균이다.

## 왜 필요한가

놓친 Positive와 잘못 예측한 Positive의 비용은 문제마다 다르다. 여러 지표를 구분하면 class 비율이 불균형할 때 높은 정확도만 보고 성능을 과대평가하는 일을 피할 수 있다.

## 핵심 공식

```text
Accuracy  = (TP + TN) / (TP + FN + FP + TN)
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
F1        = 2 × Precision × Recall / (Precision + Recall)
```

## 핵심 코드

```python
from sklearn.metrics import classification_report

print(classification_report(y_test, y_pred))
```

## 꼭 기억할 점

- class 불균형이 크면 정확도만으로 모델을 판단하지 않는다.
- 놓치면 위험한 환자 탐지에서는 재현율이 중요할 수 있다.
- 잘못된 경보 비용이 크면 정밀도를 중요하게 볼 수 있다.
