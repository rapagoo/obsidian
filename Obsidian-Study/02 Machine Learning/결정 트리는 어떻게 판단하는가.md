# 결정 트리는 어떻게 판단하는가?

## 한 줄 설명

결정 트리는 특징에 대한 질문을 순서대로 나누며 각 잎에 도달한 데이터의 class를 예측한다.

## 왜 필요한가

“이 특징이 기준보다 큰가?” 같은 규칙으로 판단하므로 사람이 모델의 분류 과정을 비교적 쉽게 해석하고 시각화할 수 있다.

## 핵심 코드

```python
from sklearn.tree import DecisionTreeClassifier

d_tree = DecisionTreeClassifier(
    max_depth=3,
    random_state=20
)
d_tree.fit(X_train, y_train)
```

## 꼭 기억할 점

- 각 질문은 class가 덜 섞이도록 데이터를 나눈다.
- Gini impurity는 class가 얼마나 섞여 있는지 나타내며 순수할수록 `0`에 가깝다.
- 깊이를 제한하지 않으면 학습 데이터를 지나치게 세밀하게 나눠 과적합되기 쉽다.
- `feature_importances_`로 분할에 많이 사용된 특징을 확인할 수 있다.
