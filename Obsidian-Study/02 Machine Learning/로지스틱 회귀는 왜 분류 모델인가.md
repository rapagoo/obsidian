# 로지스틱 회귀는 왜 분류 모델인가?

## 한 줄 설명

로지스틱 회귀는 선형 결합값을 sigmoid 함수에 통과시켜 `0`과 `1` 사이 확률로 바꾼 뒤 기준값으로 class를 나눈다.

## 왜 필요한가

생존·사망처럼 결과가 두 범주일 때 단순 선형 회귀의 제한 없는 숫자 대신 확률로 해석할 수 있는 값을 만든다.

## 핵심 코드

```python
from sklearn.linear_model import LogisticRegression

lr = LogisticRegression(
    solver="lbfgs",
    C=1.0,
    max_iter=100
)
lr.fit(X_train, y_train)
y_pred = lr.predict(X_test)
```

## 꼭 기억할 점

- 이름에 회귀가 있지만 수업에서는 이진 분류 모델로 사용했다.
- sigmoid 출력은 `0~1` 범위지만 `predict()`는 최종 class를 반환한다.
- `predict_proba()`는 class별 확률을 확인할 때 사용한다.
- `C`와 `max_iter`는 모델 동작을 조절하는 hyperparameter다.
