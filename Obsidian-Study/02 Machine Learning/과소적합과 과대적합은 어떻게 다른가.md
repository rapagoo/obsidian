# 과소적합과 과대적합은 어떻게 다른가?

## 한 줄 설명

과소적합은 모델이 규칙을 충분히 배우지 못한 상태이고, 과대적합은 학습 데이터에 지나치게 맞아 새 데이터에서 성능이 떨어지는 상태다.

## 왜 필요한가

학습 정확도 하나만 높다고 좋은 모델은 아니다. 처음 보는 데이터에서도 잘 작동하는 일반화 성능을 목표로 해야 한다.

## 핵심 판단

| 상태 | 학습 성능 | 테스트 성능 |
| --- | --- | --- |
| 과소적합 | 낮음 | 낮음 |
| 과대적합 | 높음 | 낮음 |
| 일반화가 양호함 | 높음 | 높음 |

## 꼭 기억할 점

- 과소적합은 특징이 부족하거나 모델이 지나치게 단순할 때 생길 수 있다.
- 과대적합은 데이터가 적거나 모델이 지나치게 복잡할 때 생길 수 있다.
- 결정 트리는 `max_depth` 등으로 복잡도를 제한할 수 있다.
- 데이터 분할, 검증 데이터, K-fold는 일반화 성능을 확인하는 도구다.
