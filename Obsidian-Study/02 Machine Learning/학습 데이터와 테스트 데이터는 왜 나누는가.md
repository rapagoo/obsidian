# 학습 데이터와 테스트 데이터는 왜 나누는가?

## 한 줄 설명

학습 데이터는 모델이 규칙을 배우는 데 쓰고, 테스트 데이터는 학습에 사용하지 않은 샘플에서 성능을 확인하는 데 쓴다.

## 왜 필요한가

공부한 문제의 답을 외운 것과 처음 보는 문제를 풀 수 있는 것은 다르다. 같은 데이터로 학습과 평가를 모두 하면 실제 일반화 성능을 알 수 없다.

## 핵심 코드

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    random_state=20,
    train_size=0.75
)
```

## 꼭 기억할 점

- `X_train`과 `y_train`, `X_test`와 `y_test`의 행은 서로 대응한다.
- 테스트 데이터는 모델의 `fit()`에 넣지 않는다.
- `random_state=20`은 무작위 분할 결과를 반복 실행해도 같게 만든다.
- 같은 테스트셋을 반복해서 보며 모델을 고르면 테스트셋에도 맞춰질 수 있다.
