# 손 랜드마크 좌표는 어떻게 제스처 특징이 되는가?

## 한 줄 설명

MediaPipe가 찾은 손의 21개 landmark 좌표를 손목 기준 상대 좌표로 바꾸고 크기를 정규화하면, KNN이 사용할 제스처 특징(feature)을 만들 수 있다.

## 왜 필요한가

같은 손 모양도 화면의 위치와 카메라와의 거리에 따라 좌표가 달라진다. 손목을 원점처럼 사용하고 전체 크기로 나누면 위치와 크기 차이의 영향을 줄여 손 모양 자체를 비교하기 쉬워진다.

## 핵심 코드

```python
hand_landmark = detection_result.hand_landmarks[0]
standard = hand_landmark[0]
temp = []

for lm in hand_landmark:
    rel_x = lm.x - standard.x
    rel_y = lm.y - standard.y
    temp.extend([rel_x, rel_y])

temp_array = np.array(temp).reshape(-1, 2)
max_dis = np.max(np.linalg.norm(temp_array, axis=1))

if max_dis > 0:
    temp_array /= max_dis

features = temp_array.flatten()
```

## 꼭 기억할 점

- 손 landmark는 21개이며 수업의 custom CSV에는 각 점의 상대 `x`, `y`가 저장됐다.
- 위 코드의 입력 특징 수는 `21 × 2 = 42`개다.
- 학습 데이터와 예측 데이터는 같은 특징 계산 방법과 같은 열 개수를 사용해야 한다.
- 수업에는 관절 벡터 사이의 각도 15개를 특징으로 쓰는 다른 방법도 있었다. 좌표 특징과 각도 특징을 섞어 사용하면 안 된다.
