# 원-핫 인코딩은 왜 필요한가?

## 한 줄 설명

원-핫 인코딩은 범주마다 별도 열을 만들고 해당 범주이면 `1`, 아니면 `0`으로 표시한다.

## 왜 필요한가

문자열은 많은 모델이 직접 계산할 수 없지만, 범주를 단순히 `0`, `1`, `2`로 바꾸면 없는 크기와 순서 의미가 생길 수 있다.

## 핵심 코드

```python
df_tt = pd.get_dummies(
    df_tt,
    columns=["Embarked"],
    dtype=int
)
```

결과로 `Embarked_C`, `Embarked_Q`, `Embarked_S` 같은 열이 만들어진다.

## 꼭 기억할 점

- 원-핫 열의 숫자는 크기 순서가 아니라 해당 범주 여부를 뜻한다.
- 학습과 테스트 데이터에 같은 열 구조가 필요하다.
- 수업에서는 `Sex`도 `female`, `male` 열로 직접 만들었다.
- 인코딩 전에 결측 범주를 어떻게 다룰지 정해야 한다.
