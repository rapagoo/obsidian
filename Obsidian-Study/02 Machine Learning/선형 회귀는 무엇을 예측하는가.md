# 선형 회귀는 무엇을 예측하는가?

## 한 줄 설명

선형 회귀는 입력 특징과 연속적인 수치 정답 사이의 관계를 가장 잘 나타내는 직선 또는 평면을 학습한다.

## 왜 필요한가

분류가 class를 고르는 문제라면 회귀는 판매량·점수처럼 숫자의 크기를 예측하는 문제다.

## 핵심 코드

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(X_train, y_train)
y_pred = lr.predict(X_test)
```

단순 선형 회귀는 `y = w * x + b`로 표현하며, `w`는 기울기, `b`는 편향이다.

## 꼭 기억할 점

- 회귀의 예측값은 class 번호가 아니라 연속적인 수치다.
- 실제값과 예측값의 차이를 오차 또는 residual이라고 한다.
- 오차를 단순히 더하면 양수와 음수가 상쇄될 수 있어 MAE·MSE 같은 지표를 사용한다.
