# 엘보우 방법은 군집 개수를 어떻게 정하는가?

## 한 줄 설명

엘보우 방법은 군집 수 `K`를 바꾸며 군집 내부 거리 합인 inertia를 비교하고, 감소 폭이 눈에 띄게 완만해지는 지점을 후보로 고른다.

## 왜 필요한가

K-means는 군집 수를 자동으로 정하지 않으므로 여러 `K`의 결과를 비교할 기준이 필요하다.

## 핵심 코드

```python
k_list = range(1, 11)
inertia_list = []

for k in k_list:
    model = KMeans(
        n_clusters=k,
        n_init="auto",
        random_state=20
    )
    model.fit(X)
    inertia_list.append(model.inertia_)

plt.plot(k_list, inertia_list)
```

## 꼭 기억할 점

- inertia는 각 데이터와 소속 중심점 사이 거리의 합으로, 작을수록 군집 안이 조밀하다.
- `K`를 늘리면 inertia는 계속 감소하므로 최솟값만 선택하면 안 된다.
- 꺾이는 지점이 명확하지 않을 수 있으며 수업 데이터에서는 `K=4`가 보였다.
