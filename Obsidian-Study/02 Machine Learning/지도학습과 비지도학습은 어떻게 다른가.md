# 지도학습과 비지도학습은 어떻게 다른가?

## 한 줄 설명

지도학습은 정답인 label을 함께 주고 입력과 정답의 규칙을 배우며, 비지도학습은 정답 없이 데이터의 구조나 묶음을 찾는다.

## 왜 필요한가

문제에 정답 데이터가 있는지에 따라 사용할 학습 방법과 평가 방식이 달라진다.

## 핵심 코드

```python
# 지도학습: X와 y를 함께 학습
knn.fit(X_train, y_train)

# 비지도학습: X만으로 군집 학습
kmeans.fit(X)
```

## 꼭 기억할 점

- 분류와 회귀는 지도학습에 속한다.
- K-means 군집과 PCA는 수업에서 비지도학습 흐름으로 다뤘다.
- 강화학습은 정답표 대신 보상과 벌을 통해 행동을 학습한다.
- 비지도학습에서도 실습 데이터에 확인용 `y`가 있을 수 있지만, 모델의 `fit()`에는 넣지 않는다.
