# fit과 predict는 무엇을 하는가?

## 한 줄 설명

`fit()`은 학습 데이터에서 규칙과 파라미터를 찾고, `predict()`는 학습된 규칙을 새 입력에 적용해 예측값을 만든다.

## 왜 필요한가

모델 생성만으로는 아직 데이터의 규칙을 배우지 않았다. 학습과 예측을 분리하면 어떤 데이터가 어느 단계에 쓰였는지 알 수 있다.

## 핵심 코드

```python
knn.fit(X_train, y_train)
y_pred = knn.predict(X_test)
```

## 꼭 기억할 점

- 지도학습의 `fit()`에는 입력 `X_train`과 정답 `y_train`이 함께 들어간다.
- `predict()`에는 정답을 넣지 않는다.
- `y_pred`는 `y_test`와 비교해 평가한다.
- 전처리기의 `fit()`과 모델의 `fit()`은 역할이 다르지만, 모두 학습 데이터에서 필요한 정보를 배운다는 공통점이 있다.
