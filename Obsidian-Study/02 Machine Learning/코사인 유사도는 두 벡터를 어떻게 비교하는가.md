# 코사인 유사도는 두 벡터를 어떻게 비교하는가?

## 한 줄 설명

코사인 유사도는 두 벡터가 가리키는 방향이 얼마나 비슷한지를 내적과 벡터 크기로 계산한다.

## 왜 필요한가

얼굴 이미지를 숫자 벡터로 바꾸면 픽셀을 직접 비교하는 대신 벡터의 방향을 비교할 수 있다. 수업에서는 저장된 얼굴 벡터와 웹캠 얼굴 벡터의 유사도를 구하는 데 사용했다.

## 핵심 코드

```python
def get_cosine_similarity(vec1, vec2):
    dot_product = np.dot(vec1, vec2)
    norm_v1 = np.linalg.norm(vec1)
    norm_v2 = np.linalg.norm(vec2)

    return dot_product / (norm_v1 * norm_v2)
```

## 꼭 기억할 점

- 벡터 방향이 같을수록 값이 `1`에 가까워진다.
- 두 벡터 중 하나의 크기가 `0`이면 나눗셈을 할 수 없으므로 확인이 필요하다.
- 유사도는 두 벡터의 상대적인 닮은 정도이며, 그 자체가 분류 확률은 아니다.
- 비교 전에 두 이미지에서 얼굴 encoding이 실제로 추출됐는지 확인해야 한다.
