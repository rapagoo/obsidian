# 상관계수와 heatmap은 무엇을 보여주는가?

## 한 줄 설명

상관계수는 두 수치형 변수가 함께 변하는 선형 관계의 방향과 강도를 `-1`부터 `1` 사이 값으로 나타내며, heatmap은 이를 색으로 비교한다.

## 왜 필요한가

성별·등급·나이와 생존 여부 사이에 어떤 관계가 있는지 여러 변수 쌍을 한눈에 탐색할 수 있다.

## 핵심 코드

```python
df_corr = df_tt4[["Survived", "Pclass", "Sex", "Age"]].copy()

import seaborn as sns
sns.heatmap(
    df_corr.corr(),
    cmap="coolwarm",
    annot=True,
    linewidths=1.5,
    fmt=".2f"
)
```

## 꼭 기억할 점

- `1`에 가까우면 양의 선형 관계, `-1`에 가까우면 음의 선형 관계다.
- `0`에 가깝다고 모든 관계가 없는 것은 아니다. 비선형 관계일 수 있다.
- 상관관계만으로 인과관계를 확정할 수 없다.
- 범주형 문자열은 분석 목적에 맞게 수치화한 뒤 사용한다.
