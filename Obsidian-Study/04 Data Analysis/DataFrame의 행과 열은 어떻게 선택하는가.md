# DataFrame의 행과 열은 어떻게 선택하는가?

## 한 줄 설명

DataFrame은 열 이름, 행·열 레이블, 정수 위치 또는 조건식을 이용해 필요한 부분을 선택한다.

## 왜 필요한가

전체 표에서 모델 입력에 필요한 열만 고르거나 특정 조건을 만족하는 행만 분석하려면 선택 방법을 구분해야 한다.

## 핵심 코드

```python
df_train["역명"]
df_train[["역명", "승차총승객수"]]

df_train.loc[3:5, "호선명":"승차총승객수"]
df_train.iloc[3:5, 1:4]
```

## 꼭 기억할 점

- 열 하나는 문자열, 여러 열은 문자열 리스트로 선택한다.
- `loc`은 레이블, `iloc`은 정수 위치를 사용한다.
- `loc[3:5]`는 양 끝을 포함하지만 `iloc[3:5]`는 위치 5를 포함하지 않는다.
- 머신러닝 실습에서는 `X = df.iloc[:, :-1]`, `y = df.iloc[:, -1]`로 입력과 정답을 분리했다.
