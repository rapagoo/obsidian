# 결측치는 왜 처리해야 하는가?

## 한 줄 설명

결측치는 값이 비어 있는 상태이며, 계산과 모델 학습을 방해할 수 있어 제거하거나 적절한 값으로 채워야 한다.

## 왜 필요한가

타이타닉의 `Age`처럼 일부 값이 없으면 여러 scikit-learn 모델이 그대로 학습하지 못한다. 삭제와 대체 중 데이터 손실이 적고 의미에 맞는 방법을 선택해야 한다.

## 핵심 코드

```python
df_filled = df_tt.copy()
df_filled["Age"] = df_filled["Age"].fillna(
    df_filled["Age"].mean()
)

df_dropped = df_tt.dropna()
```

## 꼭 기억할 점

- `fillna()`는 평균·중앙값·고정값 등으로 결측치를 채운다.
- `dropna()`는 결측치가 있는 행 또는 열을 제거한다.
- 평균 대체는 간단하지만 분포를 왜곡할 수 있다.
- 수업의 모델 실습에서는 필요한 열을 선택한 뒤 `dropna()`로 결측 행을 제거했다.
