# groupby는 그룹별 통계를 어떻게 계산하는가?

## 한 줄 설명

`groupby`는 같은 범주에 속한 행을 묶은 뒤 각 그룹에 합계·평균·최솟값 같은 집계 함수를 적용한다.

## 왜 필요한가

호선별 승객 수나 생존 여부별 평균 나이처럼 범주마다 통계를 비교할 때 반복문 없이 계산할 수 있다.

## 핵심 코드

```python
df_train.groupby("호선명")["승차총승객수"].mean()

df_train.groupby("호선명")["승차총승객수"].agg(
    ["mean", "min", "max"]
)
```

## 꼭 기억할 점

- 그룹 기준 열을 먼저 지정하고, 계산할 값 열을 뒤에서 선택한다.
- `sum`, `mean`, `count`, `min`, `max` 등을 사용할 수 있다.
- 여러 통계를 한 번에 구할 때 `agg()`를 사용한다.
- 먼저 조건으로 필터링한 후 다시 `groupby`할 수도 있다.
