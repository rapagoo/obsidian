# 불리언 인덱싱은 조건에 맞는 행을 어떻게 고르는가?

## 한 줄 설명

불리언 인덱싱은 각 행에 대한 `True`·`False` 결과를 마스크로 사용해 `True`인 행만 선택한다.

## 왜 필요한가

승객 수가 기준 이상인 역이나 특정 호선처럼 실제 분석 조건에 맞는 데이터만 골라낼 수 있다.

## 핵심 코드

```python
condition = (
    (df_train["호선명"] == "5호선")
    & (df_train["승차총승객수"] >= 10000)
)

df_filtered = df_train[condition]
```

## 꼭 기억할 점

- pandas 조건을 결합할 때 `and`, `or` 대신 `&`, `|`를 사용한다.
- 각 비교식을 괄호로 감싸 연산 순서를 분명히 한다.
- `df[mask]`와 `df.loc[mask]`를 사용할 수 있다.
- 수업 셀의 `df.iloc[Boolean Series]` 형태는 pandas 버전에 따라 지원되지 않을 수 있으므로 레이블 기반 불리언 선택에는 `loc`가 명확하다.
