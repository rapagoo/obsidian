# loc과 iloc은 어떻게 다른가?

## 한 줄 설명

`loc`은 행·열의 레이블을 기준으로 선택하고, `iloc`은 0부터 시작하는 정수 위치를 기준으로 선택한다.

## 왜 필요한가

인덱스 값이 실제 위치와 다를 수 있으므로 “이름이 2인 행”과 “세 번째 행”을 구분해야 한다.

## 핵심 코드

```python
df_train.loc[2, "승차총승객수"]
df_train.iloc[2, 3]

df_train.loc[3:5, "호선명":"승차총승객수"]
df_train.iloc[3:5, 1:4]
```

## 꼭 기억할 점

- `loc` 슬라이스는 끝 레이블을 포함한다.
- `iloc` 슬라이스는 Python의 일반 슬라이스처럼 끝 위치를 포함하지 않는다.
- `iloc`에는 열 이름이 아니라 정수 위치를 사용한다.
- 행을 필터링한 뒤 인덱스가 연속적이지 않아도 `iloc[0]`은 현재 결과의 첫 행이다.
