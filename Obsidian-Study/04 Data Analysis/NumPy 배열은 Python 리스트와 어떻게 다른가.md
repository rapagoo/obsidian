# NumPy 배열은 Python 리스트와 어떻게 다른가?

## 한 줄 설명

NumPy 배열은 같은 종류의 수치 데이터를 다차원으로 저장하고, 반복문 없이 요소별·벡터 연산을 수행하도록 만든 구조다.

## 왜 필요한가

머신러닝 데이터는 행과 특징으로 이루어진 수치 행렬이다. NumPy 배열은 C 기반의 연산을 사용해 큰 수치 계산을 효율적으로 처리한다.

## 핵심 코드

```python
import numpy as np

arr1 = np.array([1, 2, 3, 4, 5])
arr2 = np.array([6, 7, 8, 9, 10])

print(arr1 + arr2)  # [ 7  9 11 13 15]
```

## 꼭 기억할 점

- Python 리스트의 `+`는 연결이고 NumPy 배열의 `+`는 요소별 덧셈이다.
- `shape`은 각 차원의 크기, `ndim`은 차원 수를 알려 준다.
- `X[:, 0]`처럼 여러 행의 특정 열을 한 번에 선택할 수 있다.
- scikit-learn의 내장 데이터셋 `data`와 `target`은 NumPy 배열로 제공된다.
