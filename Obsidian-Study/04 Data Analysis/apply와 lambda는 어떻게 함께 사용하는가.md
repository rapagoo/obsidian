# apply와 lambda는 어떻게 함께 사용하는가?

## 한 줄 설명

`Series.apply()`는 열의 각 값에 함수를 적용하고, `lambda`는 짧은 일회성 변환 함수를 바로 작성할 때 사용한다.

## 왜 필요한가

문자열의 대소문자 변경, 범주 이름 변환, 조건에 따른 새 열 생성처럼 행마다 같은 규칙을 적용할 수 있다.

## 핵심 코드

```python
df_tt["Sex"] = df_tt["Sex"].apply(
    lambda x: 1 if x == "female" else 0
)

df_tt3["연령"] = df_tt3["Age"].apply(
    lambda x: "유아" if x <= 1
    else ("미성년자" if x <= 20 else "성인")
)
```

## 꼭 기억할 점

- 복잡한 로직은 이름 있는 일반 함수가 더 읽기 쉽다.
- 값 대응표가 이미 있다면 `map(딕셔너리)`가 적합하다.
- 원본 열을 덮어쓸지 새 열을 만들지 먼저 결정한다.
- 문자열을 숫자로 바꾸면 모델 입력으로 사용할 수 있지만, 숫자에 불필요한 순서 의미가 생기지 않는지도 확인한다.
